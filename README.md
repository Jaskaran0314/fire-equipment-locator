# 动火设备管理定位系统

## 项目简介

这是一个专业的动火设备管理和实时定位监控系统，通过TCP通信协议与M63定位终端连接，实现对动火设备的全方位管理和安全监控。

## 主要功能

### 🔥 动火设备管理
- **设备登记**: 新增和管理动火设备信息
- **设备列表**: 展示现有动火设备详细信息
- **设备属性**: 包含设备名称、ID、所属机构、联系人、联系方式、设备类型

### 📍 设备定位与报警
- **位置确认**: 工作人员通过地图确认设备当前位置，点击确认记录坐标
- **移动报警**: 自动检测设备移动超过20米或定位装置掉线，立即发出报警
- **轨迹管理**: 记录并展示设备历史移动轨迹
- **报警管理**: 记录报警类型、时间、位置等详细信息

### 👥 用户管理
- 管理员对用户信息进行增删改查操作
- 用户权限管理

```
miniprogram/

│   ├── index/          # 首页
│   └── logs/           # 日志页
└── utils/              # 工具函数
```

### 后端服务
- **TCP服务器**: 与M63定位终端建立连接
- **数据存储**: 动态存储定位终端信息
- **设备绑定**: 新增设备时选择并绑定定位终端

### 通信协议
- 基于M63终端通讯协议
- TCP连接方式，平台作为服务器，终端作为客户端
- 支持设备注册、心跳、位置上报等功能

## 数据库设计

### 动火设备属性表
| 字段 | 说明 |
|------|------|
| 设备名称 | 设备的名称标识 |
| 设备ID | 唯一设备标识符 |

### 报警信息属性表
| 字段 | 说明 |
|------|------|
| 设备ID | 关联的设备标识 |
| 报警类型 | 移动报警/掉线报警等 |
| 报警时间 | 报警发生的时间 |
| 报警位置 | 报警时的地理坐标 |

## 核心业务逻辑

1. **TCP连接管理**: 系统启动TCP服务器，等待定位终端连接
2. **设备绑定**: 在新增动火设备时，选择对应的定位终端进行绑定
3. **实时监控**: 持续接收定位数据，计算设备移动距离
4. **报警触发**: 当设备移动超过安全距离(20米)或终端掉线时，自动触发报警
5. **轨迹记录**: 保存设备的历史位置信息，形成移动轨迹

## 快速开始

### 环境要求
- Node.js 16+
- 微信开发者工具
- MySQL 8.0+

### 安装步骤
1. 克隆项目
```bash
git clone [your-repository-url]
cd 定位器
```

2. 安装依赖
```bash
# 后端依赖
cd server
npm install

# 前端依赖（微信小程序）
cd ../miniprogram
npm install
```

3. 配置数据库
- 创建数据库
- 导入数据表结构
- 配置数据库连接参数

4. 启动服务
```bash
# 启动后端服务
cd server
npm start

# 使用微信开发者工具打开miniprogram目录
```

## 使用说明

### 管理员操作
1. **添加设备**: 在设备管理页面点击"新增设备"，填写设备基本信息
2. **绑定终端**: 选择对应的定位终端进行绑定
3. **监控设备**: 在地图界面查看设备实时位置
4. **处理报警**: 查看报警列表，及时处理异常情况

### 工作人员操作
1. **确认位置**: 在地图上点击确认按钮，记录设备当前位置
2. **查看轨迹**: 查看设备的历史移动路径
3. **接收报警**: 收到设备异常移动或掉线通知

## 安全特性

- **实时监控**: 24小时不间断监控设备状态
- **距离报警**: 设备移动超过20米立即报警
- **掉线检测**: 自动检测终端连接状态
- **轨迹记录**: 完整记录设备移动历史
- **权限管理**: 分级用户权限控制
